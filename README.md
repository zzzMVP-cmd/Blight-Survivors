# Blight Survivors

一个游戏改编与 B站小黑子的神

---

## 玩法简介

- 选择英雄，在无尽荒芜中生存
- **键盘移动**：WASD / 方向键
- **鼠标移动**：鼠标指向目标位置，角色自动跟随
- 自动攻击敌人
- 击杀敌人获取经验升级，选择强化卡片
- 收集金币在商店购买道具
- Tab 查看增幅详情，E 查看伤害统计，ESC 暂停

- **武器**：裂地斩 —— 宽阔的近战挥砍，基础伤害 14，攻速 0.55s
- **小质变「震荡波」**：范围内额外伤害 + 范围扩增 + 小冲击波
- **大质变「地裂」**：挥砍在地面留下裂隙，持续伤害路过敌人

### 游侠 🏹

- **武器**：穿透箭 —— 高速远程箭矢，基础伤害 11，攻速 0.42s，射程 340
- **小质变「精准猎杀」**：额外穿透、对满血敌人伤害 +40%、暴击分裂箭
- **大质变「追踪」**：箭矢自动追踪敌人

### 法师 🔮

- **武器**：秘法弹 —— 爆炸魔法弹，基础伤害 22，攻速 0.95s，射程 300
- **小质变「奥术回响」**：命中范围溅射、溅射范围扩大、概率无冷却消耗
- **大质变「漩涡」**：秘法弹爆炸形成持续漩涡，持续伤害

### 盗贼 🗡️

- **武器**：影袭 —— 极快的近战连击，基础伤害 8，攻速 0.28s，攻速上限 6.0
- **小质变「影刃连击」**：连击数增加、暴击率 +12%、击杀后攻速短暂 +50%
- **大质变「飞刀」**：攻击时额外飞出飞刀

### 术士 🔥

- **武器**：烈焰喷涌 —— 向最近目标喷射火焰流，高频低伤
  - 基础伤害 6，攻速 0.18s，射程 220，攻速上限 6.0
  - 附带灼烧效果（基础烧伤 1.5）
- **小质变「炼狱」**：伤害增加、火焰长度增加、灼烧层数上限增加
- **大质变「火龙」**：喷射变为火龙旋风，大规模灼烧

### 武曲星 🌟

- **解锁方式**：使用其他英雄击杀敌人时有概率掉落碎片，集齐 5 片自动解锁
- **武器1**：龙音枪·近 —— 180° 大扇形横扫，基础伤害 50，攻速 0.30s
- **武器2**：龙音枪·远 —— 追踪龙音弹，8 秒持续，无限穿透，基础伤害 40
- **伤害限制**：单次受伤不超过最大 HP 的 10%
- **小质变「紫纹龙音」**：追踪弹速度/时长/数量、近战扇形扩至 220°、命中眩晕
- **大质变「吞噬」**：龙音弹命中 HP < 50% 敌人时概率秒杀（满级 4%）+ 最低伤害加成

## 武器系统

- 4 档品质：木 / 银 / 金 / 炫彩
- 质变系统：小质变（4 阶全满）+ 大质变（终极进化）
- 武器阶段化：1-4 阶段强化，每阶段多级
- 通用武器可被任意英雄获取

### 回旋镖 ↩

- **基础效果**：发出回旋镖直线飞行至最大射程后返回，路径上可多次命中同一敌人
- **风暴·体型**：回旋镖体积 +25%
- **风暴·极速**：飞行速度 +25%
- **风暴·分裂**：同时存在数 +1（最多 3 个）
- **风暴·碎片**：回旋镖伤害 +4；小质变后溅射碎片
- **大质变「回旋风暴」**：回旋镖旋转时持续射出碎片

### 寒冰碎片 ❄️

- **基础效果**：向最近敌人发射寒冰碎片，命中减速 42%（持续 1.4 秒），强击退
- **极寒·减速**：减速 +8%，持续 +0.4 秒
- **极寒·冻结**：叠满 3 次命中冻结敌人 1 秒
- **极寒·贯穿**：穿透 +1
- **极寒·新星**：伤害 +4；小质变后冻结触发冰霜新星
- **大质变「极寒领域」**：冻结时释放大范围冰霜新星，伤害 +30%

### 闪电链 ⚡

- **基础效果**：瞬间打击范围内单个敌人并眩晕 0.35 秒
- **雷暴·延时**：眩晕时长 +0.15 秒
- **雷暴·连锁**：闪电弹跳至 2 个邻近敌人
- **雷暴·压制**：对受控/减速敌人伤害 +50%
- **雷暴·落雷**：伤害 +5；小质变后范围落雷
- **大质变「雷暴」**：落雷范围 +30，大范围雷击

### 火旋风 🌀

- **基础效果**：向最近敌人射出火球，沿途击退并点燃（灼烧 1.2/层，持续 2.5 秒），同一火球不重复叠层
- **烈焰·范围**：火旋风直径 +25%，行进距离 +30
- **烈焰·灼烧**：直接伤害 +3；小质变后燃烧层数上限 +1
- **烈焰·分裂**：火旋风数量 +1（均匀散射）
- **烈焰·炽炎**：伤害 +3；小质变后灼烧持续 +1.5 秒
- **大质变「烈焰风暴」**：火旋风变成大范围火焰风暴

### 引力奇点 🕳️

- **基础效果**：将大范围敌人拉向自身并造成伤害，按伤害 8% 回血
  - 视觉效果：由外向内收缩的紫色圆圈
  - 溢出治疗按 18% 转化为临时全体增益（持续 3 秒）
- **引力·虹吸**：回血比例 +3%，溢出转化 +6%
- **引力·领域**：范围 +15%，增益持续 +1.5 秒
- **引力·充盈**：增益效果上限 +10%
- **引力·奇点**：伤害 +2，范围 +5%
- **大质变「万象引力」**：引力范围巨大化，持续拉扯

### 瘟疫之种 ☠️

- **基础效果**：向最近敌人发射毒弹，命中产生毒圈并叠加 1 层剧毒印记（上限 1 层）
  - 毒圈持续 5 秒，进入的怪物每 0.5 秒 +1 层印记
  - 每 3 秒触发毒伤：造成 **最大 HP × 0.5% × 印记层数** 的伤害，印记 -1
- **毒印·上限**：印记层级上限 +1，穿透 +1（最高 5 层）
- **毒印·侵蚀**：毒伤触发间隔 -0.5 秒（最低 1 秒）
- **毒印·爆发**：直接伤害 +4；小质变后死亡爆炸，造成直接伤害 × 印记层数
- **毒印·蔓延**：毒圈范围 +15，飞行距离 +30
- **大质变「剧毒绽放」**：毒弹穿透飞行，每个怪物都生成毒圈

### 裁决之剑 🗡

- **基础效果**：每 3.5 秒锁定血量低于 6% 的非 Boss 怪物（同时仅 1 把飞剑）
  - 飞剑直线飞向目标，路径上造成伤害（基础 10）
  - 到达后定身目标 0.5 秒，然后落下直接斩杀
- **裁决·阈值**：斩杀血量阈值 +1%（最高 10%）
- **裁决·锋芒**：基础伤害 +4
- **裁决·震击**：落地冲击波范围 +30，对范围内敌人造成伤害
- **裁决·禁锢**：冲击波减速 +5%，基础伤害 +3
- **大质变「天罚裁决」**：斩杀后连锁跳跃（最多 2 次），Boss 也可被斩杀

## 操作指南

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 键盘移动 |
| 鼠标移动 | 鼠标指向 → 角色跟随移动方向 |
| 1-8 | 使用道具栏物品 |
| Tab | 查看增幅详情面板 |
| E | 查看伤害统计面板 |
| ESC | 暂停游戏 |

### 触摸操作（手机/平板）

| 操作 | 功能 |
|------|------|
| 左半屏触摸拖动 | 虚拟摇杆移动 |
| 双指捏合 | 缩放画面（放大/缩小） |
| 右上角 ⏸ 按钮 | 暂停/继续游戏 |
| 点击伤害统计面板 | 切换半透明/不透明 |
| 点击道具栏 | 使用道具 |

> 触摸设备自动识别，强制使用摇杆模式，无需手动切换。竖屏时会提示横屏以获得最佳体验。

## 技术说明

- 纯 HTML/CSS/JS 单文件，可直接在浏览器中打开
- 无需安装任何依赖
- 支持键盘和鼠标两种操作模式
- 支持触摸设备（手机/平板），自动识别并启用虚拟摇杆
- 游戏数据自动保存在浏览器 localStorage

## 运行

直接用浏览器打开 `Blight Survivors.html` 即可。

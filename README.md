# Blight-Survivors
一个游戏改编与 B站小黑子的神

## 玩法简介
- 选择英雄，在无尽荒芜中生存
- WASD / 方向键移动，自动攻击敌人
- 击杀敌人获取经验升级，选择强化卡片
- 收集金币在商店购买道具
- 1-8 数字键使用道具，Tab 查看增幅详情，E 查看伤害统计，ESC 暂停

## 英雄
| 英雄 | 特点 |
|------|------|
| 战士 | 近战剑，均衡攻防 |
| 游侠 | 远程弓，射程优势 |
| 法师 | 魔法攻击，范围伤害 |
| 盗贼 | 飞镖，高速攻击 |
| 术士 | 火焰/冰霜/重力，多元素 |
| 武曲星 | 🌟 天神下凡！紫纹龙音枪·远近双持 |

## 武曲星（新增）
- **解锁方式**：使用其他英雄击杀敌人时概率掉落碎片（5 片齐全自动解锁）
- **双持武器**：紫纹龙音枪·近（180°扇形横扫）+ 紫纹龙音枪·远（追踪龙音弹）
- **伤害限制**：单次受到伤害不超过最大 HP 的 10%
- **专属升级**：武曲星·伤害（最多 10 级，每级双枪 +14 伤害）
- **质变·吞噬**：龙音弹命中 HP < 50% 的敌人时，每级 1% 概率秒杀（最多 3 级，满级 4%）

## 武器系统
- 4 档品质：木 / 银 / 金 / 炫彩
- 质变系统：小质变 + 大质变
- 武器阶段化：1-4 阶段强化

## 技术说明
- 纯 HTML/CSS/JS 单文件，可直接在浏览器中打开
- 无需安装任何依赖
- 支持键盘和鼠标两种操作模式
- 游戏数据自动保存在浏览器 localStorage

## 运行
直接用浏览器打开 `Blight Survivors.html` 即可。
